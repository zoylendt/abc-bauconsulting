# Placeholder image replacement guide

All SVGs in this folder are local placeholders, not the original photographs or licensed logos.
The layout uses the documented image proportions. Do not treat the placeholder artwork as a visual reproduction of the photographs.

## Replacing an image

1. Add the real JPEG/PNG/WebP to this folder (or a subfolder), retaining a descriptive filename.
2. In `src/_data/images.json`, change that image ID's `src` to its new `/assets/images/...` path, update `width`, `height` and `alt`, and set `placeholder` to `false`.
3. Build again. Hero/sidebar templates and Markdown image references resolve through this mapping, so the existing content files do not need to be rewritten.
4. Keep these original paths for provenance; check image rights before publishing.

Paths below omit `https://abc-bauconsulting.de/wp-content/uploads`. Add that prefix to obtain the original URL.
